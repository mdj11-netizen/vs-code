# 법인카드 사용내역 조회 웹앱

구글시트에 있는 법인카드 거래내역을, 소유자(사원명)로 검색해서 조회하는 Google Apps Script 웹앱입니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `Code.js` | 서버 로직. 시트에서 데이터를 읽어 검색/필터링해서 클라이언트에 반환 |
| `Index.html` | 클라이언트 UI (사원명 검색창 + 자동완성, 결과 표) |
| `appsscript.json` | 웹앱 배포 매니페스트 (실행 계정, 접근 권한 등) |

## 동작 방식

- 이 스크립트는 **대상 구글시트에 바인딩된(컨테이너 바인딩) Apps Script**입니다. 시트 안에서 **확장 프로그램 > Apps Script**로 만들어야 스프레드시트 ID를 코드에 직접 넣지 않아도 `SpreadsheetApp.getActiveSpreadsheet()`로 자동 연결됩니다.
- 시트 탭 이름과 무관하게 **첫 번째 시트**를 데이터 소스로 사용합니다.
- "소유자" 헤더가 있는 열을 기준으로 검색합니다. 헤더 이름이 바뀌면 `Code.js`의 `OWNER_HEADER` 상수를 수정하세요.

## 배포 방법

### 수동 배포 (clasp 없이)

1. 대상 구글시트에서 **확장 프로그램 > Apps Script**
2. 기본 생성된 `Code.gs`에 `Code.js` 내용을 그대로 붙여넣기
3. **파일 > 새 파일 > HTML**, 이름을 `Index`로 저장 → `Index.html` 내용 붙여넣기
4. 프로젝트 설정(⚙️)에서 "appsscript.json 매니페스트 파일을 편집기에 표시" 체크 → `appsscript.json` 내용으로 교체
5. **배포 > 새 배포 > 웹 앱**으로 배포 (기존 배포가 있으면 배포 관리에서 "새 버전"으로 편집)

### clasp 사용 시

```
npm install -g @google/clasp
clasp login
clasp clone <대상 시트의 Apps Script 프로젝트 스크립트 ID>   # Project Settings에서 확인
clasp push
clasp deploy
```

`clasp create --type webapp`으로 **독립 스크립트**를 새로 만들면 시트에 바인딩되지 않으니 사용하지 마세요.

## 접근 권한

`appsscript.json`의 `webapp.access`가 `"DOMAIN"`으로 되어 있어, Google Workspace 조직 계정(lezhin.com)으로 로그인한 사용자만 웹앱에 접근할 수 있습니다. 외부 공개가 필요 없다면 이 설정을 유지하세요.

## 화면 구성

- **사원명 검색**: 입력할 때만 자동완성 드롭다운이 뜨고, 목록 클릭 / 입력 후 Enter / 조회 버튼 중 하나로 조회합니다. 아무것도 입력하지 않고 조회하면 최근 내역이 나옵니다.
- **결과 표(가로 스크롤 없음)**: No., 이름, 부서, 카드번호(마스킹), 승인일, 카드명, 가맹점, 승인액, 전표상태, 일치(사용자=소유자 여부) — 딱 이 10개 컬럼만 서버에서 미리 가공해서 보내기 때문에(원본 57개 컬럼 전체를 보내지 않음) 응답이 가볍고 빠릅니다.
- **전표결재상태 배지**: 반려/거부/취소/오류 → 파스텔 레드, 종결 → 파스텔 인디고, 완료/승인 → 파스텔 그린, 미처리 → 파스텔 그레이, 처리중/진행/대기 → 파스텔 앰버. 실제 값이 이 규칙과 다르면 `Index.html`의 `statusBadgeClass` 함수를 수정하세요.
- **일치 배지**: "사용자" 열과 "소유자" 열 값이 같으면 파스텔 그린 "일치", 다르면 파스텔 앰버 "확인"으로 표시합니다.
- **식대 한도 초과 강조**: 적요에 "식대"가 포함되고 승인액이 12,000원을 초과하면 해당 행 전체를 옅은 파스텔 레드로 강조합니다. 한도는 `Code.js`의 `MEAL_LIMIT` 상수로 조정하세요.
- 상세보기 모달과 가로 스크롤 영역은 제거되었습니다 — 위 10개 컬럼이 전부입니다.

## 알려진 제약

- **사원명 없이 조회(전체 조회)** 시 시트 하단(최근) **500건까지만** 반환합니다. 전체 5천여 건을 한 번에 브라우저로 보내면 응답이 커서 실패할 수 있기 때문입니다. 500건을 넘으면 화면 상단에 "전체 N건 중 최근 500건만 표시" 안내가 뜹니다. 필요하면 `Code.js`의 `ALL_ROWS_LIMIT` 값을 조정하세요.
- 소유자 목록(자동완성용)은 `CacheService`로 30분간 캐싱됩니다(`OWNER_CACHE_TTL_SEC`). 시트에 새 소유자가 추가된 직후에는 자동완성 목록에 최대 30분 정도 지연이 있을 수 있습니다.
- 다운로드 버튼은 실제 `.xlsx` 파일이 아니라 **UTF-8 BOM이 붙은 CSV**를 내려받습니다. 엑셀에서 더블클릭하면 한글 깨짐 없이 정상적으로 열립니다.
- "부서"는 원본 시트의 `부서명` 컬럼을 우선 쓰고, 비어 있으면 `관리부서`로 대체합니다.

## 보안 관련 참고

원본 데이터에는 카드번호, 사업자등록번호 등 민감 정보가 포함되어 있습니다. 이 정보를 구글시트에 올리는 것은 사내 IT/보안팀 승인을 받은 상태입니다. 다만 이 저장소(GitHub)에는 **코드만 커밋**하고 실제 거래 데이터 파일은 `.gitignore`로 제외되어 있으니, 원본 xlsx나 시트 내보내기 파일을 커밋하지 않도록 주의하세요.
