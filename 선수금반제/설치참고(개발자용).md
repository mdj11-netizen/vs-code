# 설치 참고 (Code.gs / index.html 설정 시 확인할 것)

`사용법.md`는 이미 쓰고 계신 팀원용 문서라 그대로 두고, 이 파일에는 `Code.gs`가
기대하는 스프레드시트의 정확한 탭·열 구조만 정리했습니다. 템플릿(`선수금관리시트_템플릿.xlsx`)에
아래 탭이 없으면 실행 시 자동으로 만들어지긴 하지만(제외마스터/이력), **업로드** 탭은
이름이 정확히 일치해야 하고 직접 만들어야 합니다.

## 탭 구조

| 탭 이름 | 용도 | 만드는 사람 |
|---|---|---|
| `업로드` | ERP10 내보내기를 매달 3행부터 붙여넣는 곳 | 사람이 매달 직접 붙여넣음 |
| `제외마스터` | 영구 제외 목록 (앱이 관리) | 없으면 `Code.gs`가 자동 생성 |
| `이력` | "신규 거래처" 판정용 내부 스냅샷 (사람이 안 건드림) | 없으면 `Code.gs`가 자동 생성 + 자동으로 숨김 처리 |

## `업로드` 탭 열 구조 (A~P, 1~2행 헤더 + 3행부터 데이터)

ERP10 "거래처별계정잔액"에서 계정과목 = 원화외상매출금/미수금-거래처/미수금-직원으로
필터해서 나오는 원본 그대로, 다음 순서로 붙여넣으면 됩니다(실제 7월 데이터 파일 기준으로 확인함).

| 열 | 내용 |
|---|---|
| A | No |
| B | 거래처코드 |
| C | 거래처명 |
| D | 사업자번호 |
| E | 합계 (F+G+H) |
| F | 원화외상매출금 |
| G | 미수금-거래처 |
| H | 미수금-직원 |
| I | 거래처구분 |
| J | 종사업장번호 |
| K | 대표자 |
| L | 업종명 |
| M | 휴폐업구분 — **"정상"이 아니면 "확인필요(휴폐업의심)"으로 자동 분류됨** |
| N | 금융기관명 |
| O | 계좌번호 |
| P | 예금주명 |

Q열 이후(조직도 조회용 등)는 앱이 쓰지 않으니 있어도 없어도 무방합니다.

## 초기 제외마스터 41건 넣는 법

7월 데이터 파일의 S열(제외여부=Y)·T열(사유)에 이미 41건이 들어있습니다.
웹앱을 처음 배포한 뒤 그 41건을 하나씩 "제외등록"으로 눌러 넣거나, `제외마스터` 탭에
`거래처코드 / 거래처명 / 사유 / 등록일` 순서로 직접 붙여넣어도 됩니다(앱이 다음 분석부터
바로 반영합니다).

## 알아두면 좋은 동작 방식

- **신규 거래처 판정**: `이력` 탭에 "바로 지난 실행 시점의 거래처코드 목록"만 저장해두고,
  매번 `analyzeThisMonth()`를 실행할 때마다 그 시점 데이터로 덮어씁니다. 그래서 정확히는
  "전월"이 아니라 "바로 전 실행 시점 대비 신규"입니다 — 월 1회 사용하는 워크플로우라면
  결과가 같지만, 같은 달에 분석하기를 두 번 누르면 두 번째는 신규가 안 뜹니다.
- **제외마스터 중복 등록**: 이미 등록된 거래처코드를 다시 제외등록하면 새 행을 추가하지 않고
  기존 행의 사유만 갈아끼웁니다.
- **도메인 제한**: 코드 안에는 도메인 체크가 없습니다 — Apps Script 배포 설정의
  "액세스 권한: 키다리스튜디오(레진) 도메인 사용자만"이 유일한 방어선이니, 배포할 때
  반드시 확인해주세요.
