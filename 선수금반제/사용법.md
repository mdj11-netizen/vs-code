# 선수금/미수금 거래처 사전선별기 - 사용법

## 1. 이게 뭐 하는 도구인가요

더존 ERP10 "거래처별계정잔액"에서 미수금·선수금 관련 거래처를 매달 전체 조회하면
수백 건이 나오는데, "채권상계처리" 화면은 거래처를 하나하나 넣고 검색해야 합니다.
그런데 그중 상당수는 검색해봐도 상계할 선수금 짝이 없거나(조회안됨), 퇴사자거나,
너무 오래된 거래처라 매달 다시 확인할 필요가 없습니다.

이 도구는 그런 거래처를 한 번 등록해두면 다음 달부터 자동으로 걸러내고,
**진짜 확인이 필요한 거래처만** 추려서 보여줍니다. 신규 거래처와 휴폐업 의심 거래처는
색깔로 자동 표시됩니다.

## 2. 최초 설정 (1회만)

1. 함께 전달받은 `선수금관리시트_템플릿.xlsx` 파일을 구글 드라이브에 업로드 → 구글 시트로 열기
   (또는 "다른 이름으로 저장 → Google Sheets")
2. 상단 메뉴 **확장 프로그램 > Apps Script** 클릭
3. 기존 `Code.gs` 내용을 지우고, 전달받은 `Code.gs` 내용을 그대로 붙여넣기
4. 좌측 파일 목록에서 `+` 눌러 HTML 파일 생성, 이름을 정확히 `index` 로 지정
   → 전달받은 `index.html` 내용을 붙여넣기
5. 상단 **배포 > 새 배포** 클릭
   - 유형: **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **키다리스튜디오(레진) 도메인 사용자만** ← ⚠️ 반드시 이렇게 설정 (외부 공개 금지 요건)
6. 배포 후 나오는 웹앱 URL을 팀원들에게 공유 (구글 로그인만 되어있으면 접속 가능)

> 시트 자체 공유 설정도 "링크가 있는 모든 사용자"가 아니라 **레진 계정으로 제한**해주세요.

## 3. 매달 사용하는 방법

1. ERP10 "거래처별계정잔액"에서 계정과목 = 원화외상매출금 / 미수금-거래처 / 미수금-직원 필터 걸고 전체 조회
2. 결과를 복사해서 구글시트 **[업로드] 탭 3행부터** 그대로 붙여넣기 (헤더는 건드리지 않기)
3. 웹앱 URL 접속 → **"이번달 분석하기"** 클릭
4. 화면에 3가지 리스트가 뜹니다
   - **검색대상**: 채권상계처리 화면에서 실제로 하나씩 확인해야 할 거래처
   - **확인필요(휴폐업의심)**: 휴폐업구분이 "정상"이 아닌 거래처 (자동 감지, 확인 후 판단)
   - **자동제외됨**: 이미 제외마스터에 등록되어 있어 검색 안 해도 되는 거래처
   - 노란색 표시 = 전월에는 없던 **신규 거래처**
5. **검색대상** 목록을 보면서 채권상계처리 화면에서 하나씩 확인
   - 확인해보니 상계할 선수금이 없거나, 퇴사자거나, 너무 오래된 거래처면
     해당 행의 **[제외등록]** 버튼 클릭 → 사유 입력 (예: 조회안됨 / 퇴사자 / 오래된거래처(최근거래 2023-05))
   - 다음 달부터는 이 거래처가 자동으로 "자동제외됨"으로 빠집니다

## 4. 제외마스터 관리

웹앱 상단 **"제외마스터 관리"** 탭에서 지금까지 등록된 제외 거래처를 한눈에 확인할 수 있습니다.
잘못 등록했거나, 다시 확인이 필요해진 거래처는 **[삭제]** 버튼으로 제거하면
다음 분석부터 다시 검색대상에 포함됩니다.

## 5. 초기 데이터 안내

7월 데이터 기준으로 조회안됨 거래처 41건이 제외마스터에 미리 등록되어 있습니다.
이후부터는 매달 확인하면서 필요한 거래처를 팀원 누구나 추가/삭제하며 관리하면 됩니다.
